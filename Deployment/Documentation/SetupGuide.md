# KlayFix ERP — Client Setup Guide (1-Page)

---

## Requirements
- Windows 10/11 64-bit
- 4 GB RAM, 500 MB disk space

---

## Step 1: Install SQL Server Express
1. Open the `SQL_Express_Setup` folder from USB
2. Run `SETUP.exe`
3. Click **Basic** installation type
4. Accept the license terms
5. Wait for installation to complete (5-10 minutes)
6. When done, click **Close**

## Step 2: Install .NET 9 Runtime
1. Open `.NET 9 Desktop Runtime` installer from USB
2. Click **Install**
3. Wait for installation to complete
4. Click **Close**

## Step 3: Install KlayFix ERP
1. Copy the `publish` folder from USB to your **Desktop**
2. Open the `publish` folder
3. Double-click **KlayFix.Desktop.exe**

## Step 4: Login
- **Username:** `admin`
- **Password:** `Admin@123`

The database is created automatically on first launch.
